# 수능 던전 — 교사용 안내 (2판, 2026-11-03)

3학년 한국사 기말 이후 ⓑ 묶음. 조선 후기(교과서 144쪽~)부터 현대까지를 수능·모의평가·학력평가 한국사 기출로 푼다.
앱: https://hyonnie-t.github.io/suneung-dungeon/ · 교사 화면: 같은 주소 뒤 `?teacher=1` · 미리보기: `?preview=1`

## 수업 전에 한 번: 기숙사 배정
1. 교사 화면 → «기숙사 배정» → 토큰 넣고 «미리보기». 반마다 기숙사별 인원·평균(학기말 합계: 수행 30 + 지필 70)과 «평균 차이»가 나온다. 명단(성적 포함)은 접힌 칸 안에 있다 — 전자칠판에 띄우지 말 것.
2. 괜찮으면 «이대로 확정». 확정 뒤 다시 누르면 «덮어쓰기»를 한 번 더 묻는다(이미 기숙사를 본 학생의 태블릿에는 처음 결과가 남는다).
3. 백엔드 v141이 «새 버전»으로 재배포돼 있어야 한다(안 돼 있으면 «불러오지 못했어»).

## 한 차시 흐름 (45분)
| 구간 | 분 | 교사(전자칠판, `?teacher=1` «수업 진행») | 학생(개인 태블릿) |
|---|---|---|---|
| 입장 | 5 | 반·차시 고르고 «수업 시작». 대기실 화면에 열쇠 글자가 크게 뜬다 | 학번·이름 → (처음 한 번) 역사 성향 테스트 4문항 → 기숙사 발표 → 대기실에서 열쇠 글자 입력 |
| 묶음 ×3 | 각 10 | **시범 문제**: 문제 띄움(75초) → «분포 보기» → 풀어 주며 «🖍 단서»(자료 속 단서에 형광펜) → «📖 개념 카드» → «정답 공개» | 찍어도 되는 시범 문제를 풀고 자신감 고르고 제출 → 설명 듣기 |
| | | **보스 공격 2문제**: «다음 ▶» → 75초 → «분포 보기» → «정답 공개»(확신 오답 수가 같이 뜬다) | 칠판의 새 열쇠 글자 입력 → 앞 문제 결과·개념 카드 받기 → 공격 문제 풀고 자신감 베팅 |
| 마무리 | 5 | «마무리 ▶»: 보스 결과, 기숙사 어림 순위, 결과 화면 열쇠 글자 | 열쇠 입력 → 틀린 문제 «왜 틀렸나» 한 줄(+1) → **결과 보내기** |
| 여유 | 5 | 설명이 길어질 때 쓰는 몫. 남으면 «층 정리» 카드 | 도감 다시 보기 |

- 두 층 차시(ⓑ3·ⓑ4)는 묶음 4개 × (시범 1 + 공격 1). ⓑ5는 현대 묶음 2개 뒤 개인 모의고사 15문항(20분).
- 늦게 온 학생은 칠판의 지금 열쇠 글자를 넣으면 그 문제로 합류(놓친 문제 0점). 못 풀었는데 넘어갔으면 «못 풀었는데 선생님이 다음으로 넘어갔어»를 열어 새 글자를 넣는다.
- 태블릿을 새로고침해도 고른 답·도감·점수는 그대로 이어진다(같은 태블릿).
- 분포 막대는 토큰을 넣고 시작했을 때만 뜬다(2초마다). 점수·기숙사 포인트는 분포가 아니라 학생 «결과 보내기»로 계산한다.

## 점수 규칙 (학생 대기실에도 적혀 있음)
- 보스 공격: 🔥 확신 맞으면 +3 / 틀리면 −1, 🙂 아마도 +2 / 0, 🎲 모르겠다 +1 / 0. 시범 문제는 고르기만 하면 +1. 틀린 공격 문제에 «왜 틀렸나» 한 줄(10자 이상)마다 +1.
- 보스: 정답 1, 확신 정답 2만큼 피해. HP = 그 층 공격 문항 수 × 첫 공격 문제 공개 때 제출 인원 × 0.7.
- 기숙사 포인트(«기숙사 포인트» 탭, 제출 기준): 기숙사 평균(분모 = 명단 − 결석, **안 낸 학생 0점**) → 순위 40/30/20/10(동점은 같은 포인트) + 보스 처치·전원 제출·성장(ⓑ2부터 지난 차시보다 정답률 10%p↑) 각 +5. 결석 번호는 차시마다 표 위 칸에 넣는다.

## 교사 화면 탭
1. **수업 진행** — 위 흐름. 위쪽 띠(늘 보임): 차시·단계·🔑 열쇠 글자·타이머·보스 HP·기숙사 어림 막대. 아래 조작줄(늘 보임): ◀ 이전 / 분포 / 정답 / 단서 / 개념 카드 / 층 정리 / 다음 ▶ / 설정.
2. **기숙사 배정** — 위 «수업 전에 한 번».
3. **기숙사 포인트** — 반별 누적과 차시별 표, «많이 틀린 문항»(다음 차시 도입에서 한 문제). «표 복사».
4. **문제 은행** — 층별 묶음(시범·공격·단서)과 예비 문항, 모의고사. 정답 포함, 학생에게 보이지 말 것.
